## 🔍 Основные команды

### Запуск http-server
```bash
cd my-clicker
npx http-server
# Откройте http://localhost:8080
```

### Проверка JavaScript ошибок
```
F12 → Console → Ищите красные ошибки
```

### Просмотр localStorage (данные игры)
```
F12 → Application → Local Storage → bakery_v5
```

### Удалить сохранение (начать заново)
```
# В консоли:
localStorage.removeItem('bakery_v5')

# Или руками через Application
```

## 🎯 Быстрые ответы на вопросы

### Q: Как запустить?
**A:** Откройте `START.bat` (Windows) или выполните `npx http-server`

### Q: На каком языке?
**A:** На русском (РУ), можно легко добавить другие

### Q: Работает ли на мобильных?
**A:** Да! Полностью адаптировано (< 768px)

### Q: Где мои данные?
**A:** В localStorage браузера, автосохранение каждые 5 сек

### Q: Как удалить прогресс?
**A:** F12 → Application → Local Storage → bakery_v5 → Delete

### Q: Что такое золотой хлеб?
**A:** Редкий ресурс (5% за клик), +0.5% к множителю престижа

### Q: Можно ли модифицировать?
**A:** Да, код чистый и модульный!

### Q: Есть ли онлайн-версия?
**A:** Нет, это локальная игра (можно добавить позже)
