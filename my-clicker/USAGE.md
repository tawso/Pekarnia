# Примеры использования Pekarnia v5

## Запуск локально

### Способ 1: Через Live Server (VS Code)
1. Установите расширение "Live Server" в VS Code
2. Откройте папку `my-clicker`
3. Кликните правой кнопкой на `index.html`
4. Выберите "Open with Live Server"
5. Игра откроется в браузере на `http://localhost:5500`

### Способ 2: Через http-server (Node.js)
```bash
cd my-clicker
npx http-server
# Откройте http://localhost:8080
```

### Способ 3: Прямой запуск через браузер
```bash
# На Windows просто откройте файл:
start my-clicker/index.html
# Или drag-and-drop index.html в браузер
```

## Функциональность

### Основной геймплей
- **Клик по хлебу**: +1-∞ хлеба (зависит от уровня)
- **Уровни**: Каждые 100 опыт = +1 уровень = +1 к силе клика
- **Улучшения**: Автоматические источники хлеба

### Ресурсы
- **Хлеб 🍞**: Основной ресурс, получается от кликов и пассивного дохода
- **Золотой хлеб ⭐**: Редкий ресурс (5% за клик), бонус к престижу

### Механики
- **Пассивный доход**: Улучшения генерируют хлеб автоматически
- **Оффлайн доход**: Игра продолжает генерировать при закрытии
- **Престиж**: Сброс прогресса для получения множителей
- **Достижения**: Автоматическое разблокирование за прогресс
- **Квесты**: Ежедневные задачи для бонусов

### Интерфейс
- **Топ-панель**: Показывает текущие ресурсы (хлеб, золотой хлеб, ПС, уровень)
- **Главная кнопка**: Большой хлеб для кликов (центр экрана)
- **Панель улучшений**: Список доступных покупок справа (или внизу на мобильных)
- **Меню ⚙️**: Кнопка в правом верхнем углу для просмотра статистики

## Сохранение и синхронизация

Игра **автоматически сохраняется** каждые 5 секунд в localStorage браузера.

**Данные сохраняются:**
- Количество ресурсов (хлеб, золотой хлеб)
- Купленные улучшения
- Достигнутый уровень
- Престиж и множители
- Достижения
- Время последнего входа (для оффлайн дохода)

**Сброс данных:**
- F12 → Application → Local Storage → найти "bakery_v5" → Delete
- Или в консоли: `localStorage.removeItem('bakery_v5')`

## Управление на мобильных

- **Клик по хлебу**: Один палец
- **Кнопки покупок**: Полностью адаптированы под touch
- **Прокрутка**: На мобильных улучшения находятся внизу экрана
- **Ориентация**: Приложение перестраивается при повороте экрана

## Отладка

**Консоль браузера** (F12) показывает:
- ✅ Сохранения: "Игра сохранена"
- 💰 Оффлайн доход при входе: "Оффлайн доход: X хлеба"
- 🏆 Достижения: "🏆 [Иконка] [Название]"

Все логи помогут отследить прогресс игры.

## Математика игры

### Стоимость улучшений
- Начальная: 10, 100, 1000, 10000
- Каждая покупка увеличивает на 15%
- Формула: `cost = cost * 1.15`

### Уровни и опыт
- Опыт за клик: 1
- Опыт за пассивный доход: значение дохода
- Опыт для следующего уровня: `level * 100`

### Престиж
- Множитель престижа: `√(Всего хлеба / 1,000,000)`
- Бонус золотого хлеба: `+0.5% множителя за каждый`
- При престиже НЕ сбрасывается: престиж-очки, множитель, золотой хлеб

### Оффлайн доход
- Рассчитывается при загрузке
- Доход = (ПС * время_оффлайна_в_сек) * множитель_престижа
- Максимум оффлайна: нет (может быть много)

## Файловая структура

```
my-clicker/
├── index.html                  # Главная страница
├── README.md                   # Это файл
├── USAGE.md                    # Краткое руководство
└── src/
    ├── main.js                 # Инициализация Phaser
    ├── scenes/
    │   └── GameScene.js        # Главная логика игры
    ├── core/
    │   ├── GameState.js        # Состояние: ресурсы, уровни, прогресс
    │   ├── SaveManager.js      # Управление сохранениями
    │   ├── AchievementManager.js # Управление достижениями
    │   ├── QuestManager.js     # Управление квестами
    │   └── ResearchManager.js  # Управление исследованиями
    └── ui/
        ├── UIManager.js        # Главный менеджер интерфейса
        ├── ModalWindow.js      # Компонент модальных окон
        └── OfflineRewardWindow.js # Окно оффлайн награды
```
