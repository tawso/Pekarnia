## 📈 Математика игры

### Стоимость улучшений
```
Первая покупка: базовая цена (10/100/1000/10000)
Последующие: cost = cost * 1.15
```

### Система уровней
```
Опыт за действие = 1 (клик) или значение (пассив)
Опыт для следующего уровня = level * 100
Бонус за уровень = +1 к силе клика
```

### Престиж
```
Множитель = √(Всего хлеба / 1,000,000)
Золотой хлеб +0.5% множителя за каждый
При престиже сохраняется: множитель, точки, золото
```

### Оффлайн доход
```
Доход = (ПС * время_оффлайна_в_сек) * множитель
ПС = Σ(Улучшение.owned * Улучшение.bps)
```
