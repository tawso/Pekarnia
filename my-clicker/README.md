# Пекарня v5

Кликкер-игра на базе Phaser 3 с поддержкой мобильных устройств.

## Особенности v5

✅ **Новый адаптивный интерфейс**
- Полностью переработанный UI
- Поддержка мобильных устройств (< 768px)
- Адаптивная верстка для планшетов и ПК

✅ **Золотой хлеб**
- Редкий ресурс (5% шанс при клике)
- Увеличивает множитель престижа на 0.5% за каждый
- Отражает в топ-панели и статистике

✅ **Система квестов**
- Автоматический расчет дохода при закрытии
- Вознаграждение при возврате в игру
- Сохранение времени последнего входа

✅ **Автосохранение**
- Сохранение каждые 5 секунд
- localStorage с полной синхронизацией
- Восстановление всех прогрессов

✅ **Система достижений**
- 8+ достижений для разблокировки
- Отслеживание прогресса автоматически
- Уведомления о разблокировках

✅ **Система квестов**
- Ежедневные задачи
- Награды за выполнение
- Отслеживание прогресса

✅ **Система исследований**
- Технологии для улучшения дохода
- Покупка исследований за хлеб
- Применение множителей к улучшениям

## Как запустить

1. Откройте `index.html` в браузере
2. Начните кликать на хлеб! 🍞
3. Покупайте улучшения для пассивного дохода
4. Отслеживайте достижения и квесты

## Механика игры

### Клики
- Клик по хлебу дает 1+ (зависит от уровня) хлеба
- Каждый 100 опыт = +1 уровень = +1 к силе клика

### Улучшения
- Помощник (1 хл/сек)
- Печь (5 хл/сек)
- Пекарня (25 хл/сек)  
- Завод (100 хл/сек)

Стоимость каждого улучшения +15% после покупки

### Престиж
- Сброс прогресса для получения множителей
- Множитель = √(Всего хлеба / 1,000,000)

### Оффлайн доход
- Заработок идет за время, пока игра закрыта
- С учетом множителя престижа
- Награждается при возврате
