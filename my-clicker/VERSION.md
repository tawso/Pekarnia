## System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- ~2MB storage space (localStorage)
- No server required (fully client-side)

---

## Quick Start

### Windows
```bash
# Option 1: Run START.bat
START.bat

# Option 2: Use http-server
npx http-server

# Option 3: Direct open
start index.html
```

### macOS/Linux
```bash
# Option 1: Run START.sh
./START.sh

# Option 2: Use http-server
npx http-server

# Option 3: Direct open
open index.html  # macOS
xdg-open index.html  # Linux
```

## Game Mechanics

### Resources
- **Bread 🍞** - Main currency
- **Golden Bread ⭐** - Rare resource (5% drop rate)

### Progression
- Levels (1-∞) with increasing click power
- Passive income from 4 building types
- Prestige system with exponential multipliers
- 8+ achievements for milestones

### Save System
- Auto-save every 5 seconds
- localStorage persistence
- Offline income calculation
- No server required

---

## Performance

- **Memory Usage:** < 50MB
- **CPU Usage:** Minimal
- **Network:** None (offline-first)
- **Rendering:** 60 FPS target
- **Update Rate:** 100ms UI refresh

## Known Limitations

- localStorage size limit (varies by browser, ~10MB)
- No cloud synchronization (v6.0 feature)
- No sound/music (can add later)
- No network multiplayer (planned for v7.0)
