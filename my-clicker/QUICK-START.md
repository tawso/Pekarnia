## ❌ Если видите ошибки

### Пример ошибки:
```
❌ ERROR: Cannot read property 'add' of undefined
📍 src/ui/UIManager.js:123
```

### Что делать:
1. **Скопируйте всю ошибку** из консоли
2. **Посмотрите на файл** указанный в ошибке
3. **Проверьте** есть ли файл в папке
4. **Перезагрузите** браузер (Ctrl+Shift+R)

### Частые ошибки и решения:

**Ошибка:** `Cannot find module`
- **Решение:** Проверьте пути импортов в файлах

**Ошибка:** `Phaser is not defined`
- **Решение:** Phaser CDN не загружен, перезагрузите страницу

**Ошибка:** `TypeError: Cannot read property`
- **Решение:** Проверьте что объект инициализирован
